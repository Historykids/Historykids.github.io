# 歴史キッズ 改善版

縄文・弥生・古墳・飛鳥・奈良・平安・鎌倉・室町・戦国・江戸の202枚の歴史カードを、クイズ、図鑑、年表、3D街づくりで学べる静的サイトです。元のGitHub Pagesリポジトリに差し替えて使います。

## 変更したこと

- 遊び方（`howto.html`）：メインメニューの6番目に追加。クイズ・カード、町・農民、早押し、偉人AI、神経衰弱、ポーカー、GRID WAR、記録の8項目を手順つきで説明します。PCのバーとスマホの下部メニューから開けます。
- 偉人AI（`figures.html`）：API方式をデフォルトにし、自動接続・6人の人物・直近の会話・回答停止・エラー処理に対応。端末内モデルは起動しません。Cloudflare Workers AIサーバーと手動デプロイワークフローを同梱。現在はAPIの公開接続先が未設定のため「接続準備中」です。稼働設定は `server/figure-api/README.md` を参照してください。ブラウザに秘密キーを置きません。
- 早押し：期間「全期間」、出題「全時代ミックス」、答え方「4択」に固定。10問決戦は10時代から1問ずつランダムに選び、全期間の自己ベストを保存。ランキングは `v4_allera_ALL_choice` に分離し、速いタイムの更新をトランザクションで行います。v2/v3の過去の記録も表示できます。
- 結果画面のニックネーム欄を維持。10問決戦の全問正解・ノーミスで登録できます。ラッシュ・サバイバルには条件を説明します。
- 新しいえどげーむず（`arcade.html`）：神経衰弱は1人・CPU・同じ画面の2人対戦、12/20/30枚、2テーマ、1回のヒントと自己ベスト。GRID WARは3つの舞台、3武器、敵の経路探索、リロード・ダッシュ・シールド・コンボ、90秒と陣取りの2ミッション。
- ポーカーは通信不要のCPU3人対戦と3難易度、現在の役・必要なコール額・ベット補助・役を作る5枚の強調・行動履歴・練習成績を追加。オンライン神経衰弱の重複処理と最後のペアの得点表示も修正。

- 縄文・弥生・古墳・飛鳥・奈良・平安を各18枚、計108枚追加。各3章でクイズ・入力2倍・図鑑・検索・年表・全時代ミックスの早押し3モード・ランキング・復習・保存に対応します。既存の4時代のカード、所持金、町を引き継ぎます。
- 古代データは `data/ancient.js`。各問題に資料リンクと誤答候補を持ちます。暮らしの項目は時代名を表示し、年代に幅があるものは「ごろ」「世紀」「約〜年前」で表示します。内部の `year` は並べ替え用で、`dateLabel` がある項目はそれを画面に使います。時代区分の境目には研究や地域による違いがあります。

- 早押しを全面刷新：3秒カウントダウン、段階的な問題表示、大きな早押しボタン、難しい4択、10問決戦／60秒ラッシュ／3命サバイバル、早押し加点・コンボ、時間切れ・誤答ペナルティ、成績と全問の解説、復習への移動、キーボード操作・音切替。現在のランキングは全問正解の10問決戦のみ。過去の入力式・従来の記録も別のグループで保持します。
- クイズの誤答候補は問題ごとの一覧から選びます。無関係な語のランダムな組み合わせを廃止し、地名・元号・人物・役職・宗派など問題に近い候補を優先。全202問で同じ文字数の異なる4択と、正解が1つであることを検査します。

- ショップの「住民」から農民を1人10両で迎えられます。建物を避けて町を歩き、畑で農作業、商家で買い物、家で休憩、寺でお参り、城を見上げる、学校で読み書き、木陰で涼む動きを繰り返します。
- 「農民を見る」でカメラが農民を追い、手動で視点を動かすと追跡を解除。「動きを止める」で停止・再開できます。町画面を離れたときや別タブに移ったときは動きを止めます。マス目表示でも農民が歩きます。人数と迎えた場所は保存・バックアップの対象です。

- 全202問の4択は正解と同じ文字数。複数の答えも各部分の文字数をそろえます。はじめての正解は選択式で10両、入力式で2倍の20両。収集済みの問題では追加報酬はありません。
- 土色の地面と石の縁取り。建物は配置直後に簡易モデルを表示し、読み込み後に詳細モデルへ切り替え。通信失敗でも建物は残り、3Dを使えない場合はマス目へ自動切り替え。
- すぐに答えられるクイズ画面。選択式と入力式、ヒント、正解後の解説、復習、ふりがな切り替え。
- 時代別の収集状況、検索と章・収集状態による絞り込み、年号順の年表。
- 旧版のカード・所持金・建物を引き継ぐローカル保存。記録のJSON書き出し・読み込み。
- 購入する前に配置場所を確認。残高とマスの重複を検証し、確定時にのみ課金。移動、回転、削除、削除の取り消し。
- 3D操作パネルを町の画面に限定。WebGLを使えない環境でもマス目と建物一覧で操作可能。
- 早押しはログイン・接続に依存せず開始でき、自己ベストを保存。ランキングは既存Firebaseに接続して送信・表示。
- ランキングの週次キーと日本時間の境界を統一。投稿者の名前はHTMLとして挿入せず、テキスト表示。
- スマホの下部メニュー、タブレット・PCのサイドメニュー。江戸ゲームの戻りリンク、文字のコントラスト、viewport指定を改善。
- 未設定のFirebaseログイン、存在しないsw.js・thumbnail.png、重複する関数や浮動パネルを整理。
- 3D用のThree.js 0.160.0を同梱。既存の3Dモデルは元の `assets/_m/` を利用し、元のクレジットを保持。

## 差し替え

1. `historykids-improved.zip` を展開します。
2. `Historykids/Historykids.github.io` のリポジトリ直下へ、展開したファイルを同じフォルダ構成で追加・上書きします。
3. 既存の `assets/_m/`、画像、favicon、検索エンジン認証ファイルは残します。ZIPには変更のない大きな3D素材を含めていません。
4. GitHub Pagesの公開が完了したら、サイトを再読み込みします。旧版の進捗は同じURL・同じブラウザで引き継がれます。

GitHub Pagesの公開ブランチ `main` に反映して配信します。旧版のローカル保存と3D素材は引き継ぎます。

## 手元で試す

`historykids-preview.html` はCSS・問題データ・学習ロジックを含む確認用ファイルです。ダウンロードしてChrome、Edge、Safariなどで開いてください。クイズ、図鑑、年表、復習、マス目の街づくりを試せます。3D表示はインターネットからライブラリと元サイトの3Dモデルを読み込みます。

確認用ファイルの記録と、公開サイトの記録は別です。端末やURLを変える場合は「記録・設定」で書き出したJSONを読み込めます。確認用ファイルの「早押し」「江戸ゲーム」「偉人AI」「遊び方」「ランキング」リンクは現在の公開ページを開きます。改善された早押し画面を試すには差し替えファイルをサーバーで配信してください。

ソース一式がある場合は以下で起動できます。

```sh
npm run serve
```

`http://localhost:8000/` を開いてください。ビルド処理は不要です。

## 検証

```sh
npm ci
npm test
```

DOMによる操作検証：正誤判定、入力区切り、重複報酬の防止、復習の登録と解除、検索・絞り込み、配置・課金・移動・回転・削除・取り消し、再読み込み時の保存、旧データ移行、リセットの確認、保存できない環境、早押しの開始と全10問の完了。

公開サイトのブラウザで、クイズ・早押し・マス目の町づくり・以前の偉人AIの端末内生成・神経衰弱・GRID WAR・CPUポーカーを確認しています。3D操作、スマホ・iPad実機での表示、実際のFirebaseへの送信は未確認です。検証用ブラウザはWebGLが無効です。FirebaseのルールとApp Checkは変更せず、既存の設定を使います。接続エラー時はローカルでの学習・自己ベストを利用できます。
